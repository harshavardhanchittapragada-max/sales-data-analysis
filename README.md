
# Sales Data Analysis Project

## Overview
This project analyzes a retail sales dataset using Python to identify key business insights and trends.

## Tools Used
- Python
- Pandas
- Matplotlib
- VS Code

## Key Analysis Performed
- Dataset exploration and structure analysis
- Sales performance by product category
- Regional sales comparison
- Customer segment revenue analysis
- Monthly sales trend analysis

## Key Insights
- Technology category generated the highest revenue (~827K), though other categories performed closely.
- The West region recorded the highest sales (~710K), indicating strong regional demand.
- The Consumer segment generated the majority of revenue (~1.14M).
- Sales consistently peaked during November–December, showing strong seasonal demand.

## Business Recommendations
- Increase inventory and marketing campaigns before Q4 to maximize seasonal demand.
- Analyze the West region to understand factors driving higher sales performance.

## Limitations
The dataset does not contain Profit or Quantity columns, limiting profitability and unit-level analysis.
